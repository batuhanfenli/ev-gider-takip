# Ev Giderleri

Evin tüm giderlerini iki kişi birlikte takip etmek için yüklenebilir web uygulaması (PWA). Windows, iPhone, Android telefon ve tablette çalışır; Firebase ile tüm cihazlar anında senkronize olur. Fiş fotoğrafından otomatik giriş yapılabilir.
